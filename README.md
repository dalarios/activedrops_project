# ActiveDROPS project website

This repository contains the public companion website for **ActiveDROPS: Reverse Engineering the Programming Logic of Cytoskeletal Dynamics**.

**Website:** <https://dalarios.github.io/activedrops_project/>

The site presents the biological question, experimental–computational pipeline,
mechanical phenotype space, motor-sequence comparisons, biochemical analyses,
sequence-recombination experiment, and ThTr regulatory extension.

The working analysis code remains in the separate historical `activedrops`
repository. This repository contains only the generated public website and its
published assets.
