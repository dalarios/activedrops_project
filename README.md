# ActiveDROPS project website

This repository contains the public companion website for **ActiveDROPS: Reverse Engineering the Programming Logic of Cytoskeletal Dynamics**.

**Website:** <https://dalarios.github.io/activedrops_project/>

The site introduces the cytoskeleton as a shared engine for cellular behavior,
explains the experimental gap between in vitro and in vivo approaches, and
follows the ActiveDROPS sequence-to-behavior story figure by figure. Each
manuscript figure is paired directly with its corresponding movie; Figure 4 is
the central domain-recombination result and Figure 5 is a secondary expression-
control extension.

The working analysis code remains in the separate historical `activedrops`
repository. This repository contains only the generated public website and its
published assets.
